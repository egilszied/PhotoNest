# PhotoNest

**PhotoNest** is a private photo and video library for Windows: fast native gallery,
local face recognition and smart search, memories, and a built-in web gallery you can
open from your phone.

## Report a problem

1. Open the [**Issues**](../../issues) tab and click **New issue**.
2. Pick **Bug report** or **Feature request** and fill in the form.
3. Search [existing issues](../../issues?q=is%3Aissue) first — if yours is already there,
   add a 👍 or a comment instead of opening a duplicate.

### What helps most in a bug report

- **App version** — *Settings → About*.
- **Where it happened** — the Windows app, the web gallery in a browser, or the phone app.
- **Steps to reproduce** — what you clicked, what you expected, what happened instead.
- **Problem report file** — when PhotoNest crashes it saves a report and shows
  a dialog with **Save report** / **Open logs folder**. Attach that file to the issue.
- **Screenshots or a short screen recording**, if the problem is visual.

> ⚠️ **Privacy:** issues here are **public**. Don't post personal photos, file paths that
> contain your real name, passwords, VPN/pairing codes, or anything else you wouldn't want
> on the internet. Blur or crop screenshots if needed. Problem report files contain no
> photos, but give them a quick look before attaching.

## Security issues

Please **don't** open a public issue for a security vulnerability. Use
[**Report a vulnerability**](../../security/advisories/new) instead — it's visible only to
the developer.
